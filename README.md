# 马上到（公交地铁查询空间）

多城市公交 / 地铁查询应用，功能参照 Telegram 机器人 @Xmbus_bot（厦门公交查询机器人）移植为网页空间。

## 功能

- 实时到站：选线路 + 站名查双向到站（剩几站 / 约几分钟 / 预计到站时刻），服务端缓存防重复调用（时长可在设置里调），手动刷新
- 线路详情：双向起讫、首末班、票价、全部站点
- 站点搜索与站点到站：一个站的全部经过线路到站
- 路线规划：高德公交 / 地铁换乘方案，综合时间 + 步行 + 换乘标最优
- 行程模式：从方案一键开始行程，分步时间线推进（上车 / 下车 / 步行），当前段显示上车站实时与完整站序（还剩几站下车），换乘段实时醒目标注，状态存服务端可断点续走
- 地铁信息：按城市列出地铁线路（起讫 / 首末班 / 间隔）
- 城市切换：20+ 预置城市 + 自定义城市，收藏按城市隔离
- 附近站点：浏览器定位 + 高德周边搜索
- 统一搜索框：一个输入自动识别线路 / 站名 / 起终点 / 地铁
- 收藏：常用线路、站点、常用路线（起终点对）、常用地点（家 / 公司等命名地点，规划时一键填入）
- 我的站牌：收藏页顶部的聚合看板，一卡一「线路+站点」，打开零接口调用，逐卡手动刷新
- 设置页：界面内更换 apizero / 高德 API key（只存服务端、掩码显示、可测试可清除），以及默认城市、缓存时长

## 数据源

- 公交实时数据：apizero 实时公交 API（按次计费，空间只在手动查询时调用，不自动轮询）
- 路线规划 / 地铁线路 / 附近站点：高德地图 API

密钥管理：优先用设置页里存的 key（服务端存储），没有时回退读取 `~/.apizero_key` 与 `~/.amap_key` 文件；key 不写在代码里。
