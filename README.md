# 马上到

多城市实时公交 / 地铁查询空间，由 Telegram 机器人 @Xmbus_bot 的引擎移植而来。

## 功能

- **查车**：统一搜索框（自动分发线路 / 站点 / 站名+线路）、线路详情（双向起讫、首末班、票价、全程站点）、实时到站（双向、下一站标注、90 秒缓存、强制刷新）、站点到站
- **规划**：高德换乘方案（最优标记）、常用路线收藏、收藏路线一键开始行程
- **附近**：定位 + 高德周边站点检索
- **地铁**：按城市（厦门内置 6 线；其他城市高德检索、缓存 7 天）
- **收藏**：「我的站牌」看板（打开零接口调用、逐卡刷新）、收藏地点（按城市）
- **行程模式**：分段步进时间线、当前段上车站实时、换乘步行分钟可调（按城市+换乘站+接驳线路记忆）、赶车余量提示（赶得上 / 有点紧 / 赶不上这班）
- **城市切换**：20+ 预置城市 + 自定义，收藏按城市隔离
- **设置页**：apizero / 高德 key 界面内更换（服务端存储优先、文件兜底）、默认城市、缓存时长

## 到站画布

把常看的「站 + 线路」做成到站卡，拼成自己的通勤图：

- 到站卡固定五行：站名 / 线路 / 开往方向 / 第 1 班 / 第 2 班（无第二班显示「暂无」，无车显示「暂无车」），到站时刻为北京时间「H:MM到」
- 三种模式：**自由画布**（拖放、缩放、虚线连线）、**纵向流**（全宽大卡，手机默认）与 **文字版**（把路线树渲染成纯文字：站名/线路/开往方向/两班次，子卡树形缩进、并列标「或」，与卡片共用同一份实时状态，顶部「全部刷新」按钮可一次性手动刷新全项目卡片，走同一查询与 90 秒缓存、不改变启停状态）；模式按城市+项目记忆
- **路线树（纵向流）**：卡片按 parent 挂接成树——一张卡下面可分出多条并列备选路线（子卡缩进、虚线分支相连、卡间标「或」），每条分支再各自往下挂后续卡；带子卡的支线可一键收起为一行摘要（如「24路 · 后面还有 2 张卡」），折叠状态按项目持久化；每卡「更多」里有「＋ 在后面加一张」（在本卡名下续接新卡）、「＋ 加并列方案」（同层加备选卡）、「挂到某张卡后面」（防成环校验）和「移到顶层」；删中间卡时子卡自动改挂其父卡
- **项目**：整张图打包命名保存（如「上班」「下班」），顶部切换；项目按城市隔离，同城禁止重名，切换列表标注每项目卡数，当前项目按城市持久化
- **步骤分组**：同一步可放多个备选方案（自由画布卡面步号徽章；纵向流已由路线树取代步号驱动）
- 卡片操作：开始（只立即查一次、无自动轮询）/ 停止（待机不查车）、手动点查更新、方向行 ◀ ▶ 三角一键切换开往终点（免打字）、点选优先填卡（站名 / 线路 / 方向点选，沉淀复用）、空白五卡直接放置（零接口调用）；卡面为「核心信息 + 一行操作 + 更多展开区」的紧凑结构
- **模块库**：调好的卡可存库，任何项目一键调用独立副本
- 规划结果可一键「转到画布」成链；全部内容服务端自动保存

## 数据源

- apizero 实时公交接口（stations / query / line，均带 city 参数）
- 高德地图：输入提示、地理编码、公交换乘规划、地铁线路检索、周边站点

密钥不入库：服务端设置存储优先，其次读运行时密钥文件（`~/.apizero_key`、`~/.amap_key`，权限 600）。
